# 努荋弄花 NYHR Floral Design

品牌形象網站，使用原生 HTML、CSS 與 JavaScript，無需建置即可部署到 GitHub Pages。

## 部署

在儲存庫 Settings → Pages，選擇 Deploy from a branch、main、/(root)，按 Save。

## 維護

- 文案與照片：index.html
- 版型與手機樣式：styles.css
- 手機選單與照片放大：script.js
- 壓縮後的作品與課程照片：assets/

訂花與課程按鈕導向品牌 Facebook，由工作室私訊確認；沒有購物車、付款或虛構的預約成功狀態。

## 視覺方向

參考 Maison Haru 的置中品牌、寬留白、照片與文字交錯、細框按鈕；另研究一花一草與微光花藝的作品導覽。原創撰寫頁面與品牌文案，不使用參考網站的照片、商標、程式碼或商品資料。桌面內容最大寬度1160px，雙欄，手機改為單欄。使用裝置現有中文字體與 Georgia 字體，不隨附第三方字型檔。
